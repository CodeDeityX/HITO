# Security Policy

HITO is a local developer tool that may inspect project state and persist
governed metadata.

Do not publish secrets, private repositories, customer data, or credentials
in a public issue.

Prefer GitHub private vulnerability reporting when available. If private
reporting is unavailable, contact the maintainer through the CodeDeityX
GitHub profile and request a private channel before sharing exploit details.

Ordinary HITO status/projection paths should not require model-provider
network calls or target-project execution.
