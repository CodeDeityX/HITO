# HITO Human UI Review

The final human acceptance check verifies that the VS Code surface is a
projection of the same governed truth used by the CLI.

Required views:

1. HITO: Project Overview
2. HITO: Engineer Detail
3. HITO: Forensic Detail
4. HITO: Agent Context

Acceptance requires:

- the intended project root is active;
- the UI does not claim knowledge HITO has not established;
- UNKNOWN remains UNKNOWN;
- protected scope is not presented as permission;
- CLI and IDE semantic identity agree;
- Agent Context is a projection, not a separate authority;
- viewing HITO does not mutate project source.

Do not run `init` or `intake` merely to make a screenshot pass.
