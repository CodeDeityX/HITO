# Proposed HITO community launch on X — drafts, not posted

## Post 1

🐸 HITO v0.1.0-rc.1 is public.

A local-first Semantic Continuity System for software projects: preserve what is known, what remains unknown, and what the evidence supports across humans, AI agents, and sessions.

Contributors & critics welcome:
https://github.com/CodeDeityX/HITO

## Post 2

HITO does not pretend to understand every file or behavior in a repository. It preserves the boundary between established, partial, unknown and indeterminate, with a shared semantic identity across CLI, VS Code and agent context.

Help us test that claim.

## Post 3

Areas where I'd especially welcome help: structural discovery, graph/AST provider interfaces, VS Code UX, onboarding, Linux/macOS qualification, and reproducible project-memory tests.

Bugs, falsifications, RFCs and PRs are welcome.

## Post 4

This is a release candidate, not a promise of perfection.

If HITO hides known evidence, invents certainty, or loses meaning across handoffs, please report it with a reproducible example. That is how this project will improve.
