# Community Discussions plan

GitHub Discussions must be enabled manually (Repository Settings > General > Features > Discussions) or by a separately authorized API action. This file does **not** enable it.

Suggested categories:

- **Announcements:** maintainer release and maintenance notices.
- **Ideas:** bounded product improvements and pain points.
- **Q&A:** usage and first-run questions.
- **RFCs:** architecture or semantic-authority proposals, with alternatives and falsification tests.
- **Show and tell:** examples, demos, and reproducible observations using nonprivate material.

Suggested first pinned thread: **Welcome to HITO — start here**. Link Quick Start, Limitations, Contributing, and good-first-issue candidates. Invite negative test results as well as successes.

Moderation: follow CODE_OF_CONDUCT.md. Move secret-bearing reports to SECURITY.md, never public issues.
