# HITO Brand System

The canonical HITO mascot is the **HITO Frog**.

Primary phrase:

> **Observe. Understand. Preserve. Leap.**

Public-facing line:

> **HITO — Know where your project stands before you leap.**

## Canonical asset

The approved canonical mascot is the pixel-art HITO Frog carrying the
project-continuity terminal backpack.

The repository asset family is:

```text
media/hito-frog-master.png   canonical 1024 px master
media/hito-512.png           large derivative
media/hito-256.png           documentation / profile derivative
media/hito-128.png           VS Code extension / product icon
media/hito-64.png            compact derivative
media/hito-32.png            small-icon derivative
media/hito.svg               monochrome VS Code Activity Bar glyph
```

All raster derivatives are deterministic nearest-neighbor reductions of the
same approved master. They are one mascot identity, not separate characters.

## Meaning

The frog represents:

- observation before action;
- continuity through transformation;
- adaptation without identity loss;
- deliberate movement rather than indiscriminate change;
- carrying project continuity across environments.

The terminal backpack means:

> **The frog carries project continuity with it.**

## Visual direction

Preferred visual era:

> **1987–1993 workstation / UNIX / early-Linux / terminal culture**

Use terminal black, phosphor or moss green, CRT cream/off-white, muted
gray-green, restrained amber for warning, and restrained red for contradiction
or blocking states.

Avoid glossy 3D SaaS branding, rainbow AI gradients, generic AI sparkles,
cyberpunk clutter, childish presentation, and photorealistic frog branding.

The same frog may appear as Core, Explorer, Guardian, Navigator, MRI,
Archivist, Creator, UNKNOWN, Contradiction, or Result roles. These are roles
of the same canonical mascot.
