# HITO Architecture

HITO is a Semantic Continuity System for engineering projects.

Its four coordinates are:

```text
IDEA
WHAT
HOW
RESULT
```

HITO distinguishes governed project truth from projections:

```text
PROJECT / HITO STATE
        │
        ├── CLI projection
        ├── VS Code projection
        └── Agent Context projection
```

The projections should agree on the same semantic identity. A projection is
not a new canonical authority.

The current accepted R10O-E2 lineage includes bounded structural discovery.
That structural evidence is useful for HOW, but it is not accepted as a
universal repository graph authority.

The current canonical persistence namespace remains `.maat/`.
