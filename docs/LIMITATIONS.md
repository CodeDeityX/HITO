# HITO Limitations

The first public release candidate is intentionally bounded.

- R10O-E2 is not accepted as a complete repository structural authority.
- The current release line is Windows-first.
- HITO does not prove runtime behavior merely by reading source files.
- Ordinary semantic status/projection should not require target-project execution.
- The accepted local status path does not require a frontier-model provider.
- Repository prose is evidence, not automatically accepted intent authority.
- UNKNOWN is an intentional state and should not be replaced with a plausible guess.
- The canonical persistence namespace remains `.maat/`.
- Current experiments do not justify claiming HITO is universally necessary for every coding agent or repository.
