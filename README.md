# HITO

**Semantic Continuity for Engineering Projects**

**Observe. Understand. Preserve. Leap.**

HITO helps a software project preserve what it means while its files,
implementations, humans, AI agents, sessions, machines, and tools change.

Git is excellent at remembering **what changed**.

HITO is designed to preserve a governed view of:

- what the project is trying to become;
- what is currently established;
- what remains UNKNOWN;
- what evidence supports a claim;
- what is protected;
- what contradicts what;
- what changed in project meaning;
- what the next justified action is;
- why that action is justified.

## The four coordinates

```text
IDEA  →  WHAT  →  HOW  →  RESULT
```

**IDEA** — why the project exists.  
**WHAT** — what the project is intended to become.  
**HOW** — how the current implementation realizes that intent.  
**RESULT** — what is actually demonstrated now.

> **Never let HOW silently redefine WHAT.**

## Core principle

> **The project owns its truth. The agent consumes a bounded projection of that truth.**

HITO is not intended to make an AI agent the canonical owner of a project.
Its state is designed to survive individual agents, chats, IDE sessions,
machines, and implementation changes.

## Current release line

This repository is preparing **HITO v0.1.0-rc.1** from the accepted
R10O-E2 engineering lineage.

The accepted role is intentionally bounded:

> **Semantic/governance authority with explicit structural limitations.**

HITO does not claim to be a complete universal repository structural authority.

## VS Code

The extension exposes human-facing views including Project Overview,
Guided Project, Engineer Detail, Forensic Detail, and Agent Context.

The UI is a projection of the same governed HITO state used by the CLI.
It is not a second authority.

## Persistence namespace

The product is called **HITO**, but the current canonical persistence
namespace remains `.maat/`. Renaming persistence is a migration decision,
not a branding decision.

terminal culture.

is the simplified monochrome Activity Bar glyph used inside VS Code.
